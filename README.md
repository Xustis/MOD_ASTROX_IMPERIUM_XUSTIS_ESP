ASTROX IMPERIUM – Traducción al Español

Proyecto de traducción al español para ASTROX IMPERIUM.

Este repositorio contiene los archivos de localización necesarios para jugar en español.
Los archivos fuente se encuentran dentro de la carpeta:

```
/src

```

Traducción completa/parcial de textos del juego

⚠️ La traducción está en progreso y puede contener errores o textos pendientes de revisar.

📥 Instalación

Descarga la última versión desde la sección Releases.

Extrae el contenido.

Copia los archivos dentro de la carpeta del juego correspondiente a localización.

Inicia el juego.

Selecciona el mod.

Se recomienda hacer copia de seguridad antes de reemplazar archivos aunque en este repo hay un backup pero la versión puede diferir.
